# Contributing to Cloud Native UEMOA

Thank you for your interest in contributing to the **Cloud Native UEMOA** community! 🙌

There are many ways to contribute:

- Propose a talk or workshop (see the **Speaker Proposal** issue template),
- Suggest topics for future meetups,
- Share demos, code samples, or tutorials,
- Help organize events (logistics, communication, moderation),
- Contribute to documentation or translation (English / French),
- Support the organization of **KCD UEMOA**.

## How to Start

1. Read our `CODE_OF_CONDUCT.md`.
2. Check existing issues and discussions.
3. Open a new issue if you have:
   - A **talk idea** → use the `speaker-proposal` template.
   - A **meetup idea** → use the `meetup-proposal` template.
4. If you want to become a co-organizer, open an issue titled:
   > "Co-organizer application – [Your Country]"

## Pull Requests

For documentation, agenda updates, or minor improvements:

1. Fork the repository.
2. Create a branch: `feature/your-change`.
3. Commit and open a Pull Request with a clear description.

We welcome contributors from all UEMOA countries and all skill levels.

Together, we can grow a strong, sovereign and collaborative Cloud Native ecosystem in West Africa. 🌍
