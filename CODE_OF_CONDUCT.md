# Code of Conduct

Cloud Native UEMOA follows the **CNCF Code of Conduct**.

All community members, organizers, speakers, sponsors and attendees are expected to:

- Be respectful and inclusive,
- Avoid harassment, discrimination or offensive behavior,
- Foster a welcoming environment for all skill levels and backgrounds.

The full CNCF Code of Conduct is available at:

https://github.com/cncf/foundation/blob/main/code-of-conduct.md

By participating in this community (events, GitHub, Slack, etc.), you agree to abide by this Code of Conduct.

If you experience or witness a violation, please contact the organizers or CNCF staff.
