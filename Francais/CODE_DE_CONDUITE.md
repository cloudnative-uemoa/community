# Code de conduite – Cloud Native UEMOA

La communauté **Cloud Native UEMOA** adopte et applique le **Code de conduite officiel de la CNCF**.

Tous les membres de la communauté (organisateurs, intervenants, participants, sponsors, contributeurs GitHub, etc.)
s’engagent à :

- Faire preuve de respect et de bienveillance,
- Éviter tout comportement harcelant, discriminatoire ou offensant,
- Favoriser un environnement accueillant pour tous les niveaux et tous les profils,
- Respecter les différences de culture, de pays, de genre, d’expérience et d’opinion.

Le texte complet du Code de conduite CNCF est disponible ici (en anglais) :  
https://github.com/cncf/foundation/blob/main/code-of-conduct.md

En participant à la communauté Cloud Native UEMOA (événements, Slack, GitHub, réseaux sociaux),
vous acceptez de respecter ce Code de conduite.

En cas d’incident ou de comportement contraire au Code de conduite,  
merci de contacter les organisateurs du chapter ou l’équipe CNCF.
