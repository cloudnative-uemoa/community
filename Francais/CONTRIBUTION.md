# Contribution – Cloud Native UEMOA

Merci de votre intérêt pour la communauté **Cloud Native UEMOA** 🙌

Il existe de nombreuses façons de contribuer :

- Proposer une **conférence, un lightning talk ou un atelier**,
- Suggérer des thèmes pour de futurs meetups,
- Partager des démos, du code, des tutoriels ou des retours d’expérience,
- Aider à l’organisation (logistique, communication, modération),
- Contribuer à la documentation et à la traduction (français / anglais),
- Soutenir la préparation de **KCD UEMOA**.

---

## Comment démarrer

1. Lisez d’abord `CODE_DE_CONDUITE.md`.
2. Consultez les issues existantes dans le dépôt.
3. Si vous avez :
   - Une **idée de talk** → utilisez le template `proposition-intervenant.md`.
   - Une **idée de meetup** → utilisez le template `proposition-meetup.md`.
4. Pour devenir **co-organisateur** dans votre pays, ouvrez une issue intitulée :  
   > `Candidature co-organisateur – [Votre pays]`

---

## Pull Requests

Pour des modifications de documentation, d’agenda ou de contenu :

1. Forkez le dépôt.
2. Créez une branche : `feature/nom-de-votre-changement`.
3. Faites vos modifications.
4. Ouvrez une Pull Request avec une description claire.

Nous accueillons avec plaisir les contributions de tous les pays de l’UEMOA et de tous les niveaux d’expérience.

Ensemble, construisons un écosystème Cloud Native **fort, souverain et collaboratif** en Afrique de l’Ouest 🌍
